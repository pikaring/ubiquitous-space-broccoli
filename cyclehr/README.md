# CycleHR

サイクリング用Pebbleウォッチフェイス。直近60分の心拍数を1分ごとに記録し、
心拍ゾーン別に色分けした棒グラフで表示します。

## 画面構成（上から）

1. **天気** — アイコン / 気温(°C) / 天候（Open-Meteo、APIキー不要、30分ごと更新）
2. **時刻** — 大きな時刻 + AM/PM + 曜日・日付（12/24時間表示は本体設定に追従）
3. **現在心拍数** — ハートアイコン + bpm（15秒間隔でセンサーをサンプリング）
4. **1-MIN HR ZONES** — 直近60分の心拍を1分1本の棒グラフで表示。
   ゾーン色: Z1=グレー / Z2=青 / Z3=緑 / Z4=黄 / Z5=赤
5. **凡例** — Z1〜Z5

履歴はウォッチフェイスを閉じても保存され、再表示時に経過時間ぶんシフトして復元されます。

## 心拍ゾーン

`src/c/cyclehr.c` の `MAX_HR`（デフォルト190）を自分の最大心拍数に変更してください。
ゾーン境界は最大心拍数の 60% / 70% / 80% / 90% です。

## 対応機種

- basalt (Pebble Time) — 心拍センサーなし。グラフは空のまま
- diorite (Pebble 2 HR) — モノクロのため棒・凡例は白で表示
- emery (Pebble Time 2) — フルカラー + 心拍。参考画像と同じレイアウト

## ブルベ機能

GPXとスタート時刻を設定すると、天気の行がブルベの進捗表示に切り替わります。

- 左側に貯金を出します（例 `+54m`）。いまの位置の制限時刻までの残り時間です。30分以上は緑、30分未満は黄、マイナスは赤で表示します。位置の取得が10分以上途絶えると `?` が付きます。
- 右側に次の目標までの距離を出します（例 `PC3 12.5km`）。
- 24時間表示のときは、時刻の横にゴールまでの距離を出します。
- 走行中は、毎時0分に2回振動します。
- スタート前は `START` とスタート日時、ゴール後は `GOAL!` とゴール時点の貯金を出します。
- 設定を消すと天気の表示に戻ります。進捗を出している間、天気は隠れます。

### 設定

1. Pebbleアプリで、このウォッチフェイスの設定を開きます。
2. GPX、スタート日時、キューシートの総延長を入れて「計画を作る」を押します。
3. 表に出た制限時刻を、公式のキューシートと見比べてから「保存して時計に送る」を押します。

設定ページは `config.html` で、`https://pikaring.github.io/ubiquitous-space-broccoli/cyclehr/config.html` で公開する前提です。URLは `src/pkjs/index.js` の `CONFIG_URL` で変えられます。

GPXには、通過チェックとPCをウェイポイントとして入れておいてください。名前が `PC1`、`通過C1` のように始まっていると、時計には `PC1`、`C1` と出ます。

### 計算の内容

- 制限時刻は、標準的な規定で計算します。開時刻は200kmまで34km/h、400kmまで32km/h、600kmまで30km/hです。閉時刻は最初の60kmが20km/hに1時間を足した値、そこから先は15km/hです。ゴールの制限時間は、200kmが13時間30分、300kmが20時間、400kmが27時間、600kmが40時間です。
- PC地点の距離は、整数kmに丸めてから計算します。公称距離は、総延長を100km単位で切り捨てた値です。
- キューシートの総延長を入れると、GPXの距離をその値に合わせます。BRM912北海道300km函館では、入れないとPC2とPC4の閉時刻が4分ずれました。入れると、全地点で公式のキューシートと一致しました。
- スマホ（PebbleKit JS）が2分ごとにGPSを取り、コース上の位置を求めて時計に送ります。時計は制限時刻を絶対時刻で受け取るので、次の更新までのあいだも貯金は毎分減っていきます。
- 同じ道を往復する区間や、スタートとゴールが同じ場所のコースでも取り違えないよう、前回の位置との連続性で位置を決めます。

### 制限

- 実機での走行は未確認です。計算と位置合わせは、BRM912のGPXで作った走行データを使って確かめました。
- 600kmを超えるブルベには対応していません。開閉時刻の計算を照合したのも、300kmだけです。
- コースから500m以上離れていると、位置を更新しません。
- 位置の取得間隔が5分以上になると、通過チェックへの寄り道のような往復区間の折り返し付近で、距離が最大2km強ずれることがあります（貯金にして最大9分）。次に取得できたときに戻ります。
- 補給の情報は出しません。GPXに入っていないためです。
- ウォッチフェイスはボタンを受け取れないので、PC通過を手で入力する機能はありません。位置はGPSだけで合わせます。
- コースは200mごとに間引いて保存します（約13KB）。

## ビルド

```sh
cd cyclehr
pebble build
pebble install --emulator emery   # エミュレータ
pebble install --phone <IP>       # 実機
```

エミュレータでは心拍データが無いため、グラフ確認には実機(diorite/emery)が必要です。
天気はスマホの位置情報を使用します（`capabilities: location`）。
