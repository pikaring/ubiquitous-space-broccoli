# ブルベ キューシート生成ツール

GPXファイルと主催者配布のExcelキューシートから、**iPhoneで見やすい単一HTML**（簡易版＋詳細版・オフライン動作・ダークモード対応）を自動生成する静的Webアプリです。

- バックエンド不要。GitHub Pages / Cloudflare Pages にそのまま置けます
- **ファイルはブラウザ内だけで処理**し、外部には一切送信しません
- 元になった仕様は [`docs/spec.md`](docs/spec.md)

## 使い方

1. `index.html` をブラウザで開く（サンプル読込を使う場合はローカルサーバ経由）
2. **STEP1** GPX（必須）とExcel（任意）をドラッグ＆ドロップ
3. **STEP2** シート種別（簡易／詳細）と列の対応を確認（自動推定済み。違っていればプルダウンで修正）
4. **STEP3** 大会名・出走日時・想定速度などを設定して「キューシートを生成する」
5. **STEP4** プレビューを確認して「HTMLをダウンロード」

生成物は単一HTMLなので、iPhoneの「ファイル」アプリやDropbox等に置いておけば、圏外でも閲覧できます。

### ローカルで動かす

```bash
cd brevet-cuesheet
python3 -m http.server 8000   # http://localhost:8000/ を開く
```

`file://` で直接開いても動作しますが、「サンプルデータで試す」だけは `fetch` が使えないため利用できません。

### 公開する（GitHub Pages）

`brevet-cuesheet/` 以下をそのまま公開ディレクトリに置くだけです（ビルド不要）。

## 生成されるHTMLの機能

| | 簡易版 | 詳細版 |
|---|---|---|
| 表示対象 | PC・通過チェック・Start/Goal | 全ての曲がり角＋CP |
| 距離・Open/Close | ○ | ○ |
| ETA（速度連動・Close余裕で色分け） | ○ | −（天気パネル内でのみ使用） |
| 休憩・仮眠の加算（以降のETAを一括シフト） | ○（0〜24時間） | − |
| 距離補正ステッパー（±0.1／±1km） | ○ | ○ |
| 天気・地図パネル（タップで初めて通信） | − | ○ |
| ダークモード（OS設定に追従） | ○ | ○ |
| 日出・日没の自動計算 | ○ | − |

- 速度・距離補正・出走日時・休憩時間は `localStorage` に保存され、次に開いたときも復元されます
- 天気は [Open-Meteo](https://open-meteo.com/)（APIキー不要）、地図は OpenStreetMap の埋め込みを閲覧時に取得します
- 印刷用スタイルを同梱（設定バー・天気パネルは印刷されません）

## iPhoneで見るとき（重要）

生成したHTMLを「ファイル」アプリからChrome／Edgeで開くと、ブラウザは `edge://external-file`（Chromeは `chrome://external-file`）という内部スキームで表示します。
**iOSはこの状態からの外部通信（fetch・iframe）を一律で禁止**しているため、天気と地図は表示できません。ネットワークやプロキシの問題ではありません。

| 開き方 | キューシート・ETA・距離補正 | 天気・地図 |
|---|---|---|
| 端末内のファイルとして開く（オフライン可） | ○ | ×（iOSの制限。地図アプリへのリンクは使えます） |
| https のURLから開く | ○ | ○ |

生成物はこれを検出して、待たずに理由を表示し、OpenStreetMap／Apple マップ／Googleマップへのリンクを出します（リンクは内部スキームからでも開けます）。

天気・地図も使いたい場合は、生成したHTMLを https で開ける場所に置いてください。
このリポジトリで公開しているなら、生成物を `brevetcue/sheets/` などに置けばそのままURLになります。
電波の無い区間に備えるなら、**同じファイルを端末内にも保存しておく**運用（オンラインではURL版、圏外ではファイル版）が確実です。

## 入力データの扱い

### GPX

RideWithGPS等の書き出しを想定。`trkpt` から Haversine距離を積算して累積距離配列を作り、`wpt` はコース上の位置（km）とコースからの離れ具合を計算して保持します。

### Excel（主催者ごとに書式差が大きい）

自動推定したうえで、STEP2で必ず確認できるようにしています。対応済みのゆらぎ：

- シート構成：1シートのみ／簡易＋詳細の2シート／説明資料シート混在
- 距離：積算距離のみ／区間距離のみ（積算を自動復元）／`40.6km` のような文字列
- 時刻：Excelシリアル値（`0.75`＝18:00）／24時間超の `[h]:mm`（`1.35`＝32:24）／日付込みシリアル（`46208.005…`）／`12日 08:12`／`9/12 8:12`／`翌03:00`／`3日目 05:00`
- Open/Close：両方あり／Closeのみ／時刻なし（ACP基準で補完可）
- 種別：種別列から判定／地点名のキーワード（PC・通過・写真・クイズ・Start・Goal）から判定／詳細シートの進路欄に `PC1` 等が入る書式

Open列とClose列はそれぞれ独立に単調増加するものとして日跨ぎを解決します（「次のCPのOpen ＜ 前のCPのClose」で誤って1日進めないため）。

### GPXだけでも生成できます

Excelが無い場合は、
- GPXのウェイポイント名（`PC1…`, `通過C1…` など）＋始終点からCPを構成
- Open/Close を ACP基準（上限34/32/30/28km/h・下限15km/h、認定距離ごとの制限時間）で補完
- 曲がり角をGPXの方位変化から自動抽出（進路とアイコンのみ。道路名・ランドマークはExcelの記述が必要）

これらを使った場合は生成時に警告が出ます。**必ず主催者の公式キューシートで確認してください。**

## 座標マッチング

単純な最近傍スナップではなく、線形補間で求めています（仕様書5章）。

1. `trkpt` 列から累積距離配列 `cum[]` を作成（Haversine距離の積算）
2. `scale = Excel総距離 / GPX総距離` でスケール補正
3. 目的距離 `d` に対し `d / scale` が入る区間を二分探索
4. 区間内を線形補間して緯度経度を算出
5. 進行方位はその地点から先およそ200mの区間から算出（天気パネルの向かい風／追い風判定に使用）
6. CP名がGPXのウェイポイント名と一致した場合（バイグラム類似度0.5以上・距離差2km以内・コースから300m以内）は、そのウェイポイント座標を優先

STEP4の「座標マッチング結果」で、各地点の座標・方位・取得方法（距離補間かウェイポイントか）を確認できます。

## ディレクトリ構成

```
brevet-cuesheet/
├── index.html              生成ツール本体
├── assets/app.css
├── js/
│   ├── util.js             距離・方位・時刻・日出日没
│   ├── gpx.js              GPX解析／累積距離／線形補間／方位
│   ├── turns.js            曲がり角の自動抽出
│   ├── xlsx-import.js      Excel読取・見出し/列推定・時刻パーサ
│   ├── match.js            Excel×GPXの突き合わせ・ACP時刻計算
│   ├── template.js         出力HTMLテンプレート（CSS＋ランタイム）
│   └── app.js              画面制御
├── vendor/xlsx.full.min.js SheetJS 0.18.5（同梱：オフラインでも動くように）
├── samples/                デモ用の架空コース（GPX/Excel）
├── tests/
│   ├── make-samples.mjs    サンプル生成
│   └── e2e.mjs             Playwrightによる通しテスト
└── docs/spec.md            仕様書
```

## 開発

```bash
node tests/make-samples.mjs                 # サンプルGPX/Excelを再生成
node tests/e2e.mjs                          # 通しテスト（要 playwright）
OUT_DIR=./out node tests/e2e.mjs            # 生成物とスクリーンショットの出力先を指定
```

`tests/e2e.mjs` は、サンプル読込 → 列の自動推定 → 生成 → プレビュー操作（速度・距離補正・休憩・タブ・天気パネル）→ ダークモード → GPX単体生成までを検証します。

## 既知の制約

- 道路名・ランドマーク注記はExcelの自由記述に依存します。Excelに無い場合は自動生成できません
- 天気予報は開催の概ね16日前から（Open-Meteoの仕様）。範囲外のときは地図のみ表示します
- 地図・天気パネルの閲覧にはネット接続が必要です（キューシート本体はオフラインで閲覧可）。
  `api.open-meteo.com` と `www.openstreetmap.org` に届かない環境（オフライン、社内・庁内プロキシやURLフィルタ）では
  地図が白いままになり、天気は10秒でタイムアウトします。その場合はパネルに理由と再試行ボタンが出ます
- iOSのChrome／Edgeで端末内のファイルとして開いた場合、天気と地図は表示できません（上記「iPhoneで見るとき」参照）
- 主催者のExcel書式は今後も新しいパターンが出るため、STEP2での目視確認を前提にしています
- 生成HTMLは端末のタイムゾーンで時刻を扱い、天気は `Asia/Tokyo` で取得します（国内開催を想定）
